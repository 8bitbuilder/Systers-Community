# 🌷 Systers Member Garden

A tiny, cute desktop display made by the Systers community! Every member can contribute by adding their name to the garden.

## Run it

Make sure Python 3 is installed, then run this from the repository root:

```bash
python main.py
```

On some systems, use `python3 main.py` instead.

The app uses Python's built-in `tkinter` library, so you usually don't need to install anything else.

## Add yourself to the garden

1. Fork this repository on GitHub.
2. Clone your fork to your computer.
3. Create a branch for your change.
4. Open `community/members.json`.
5. Add your name as a new entry, following the examples already there.
6. Commit and push your branch, then open a pull request!

Please add only information you're comfortable sharing with the club. A first name or nickname is perfect.
