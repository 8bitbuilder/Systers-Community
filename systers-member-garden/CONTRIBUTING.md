# 🌱 Add yourself to the Systers Garden

Thanks for contributing!

1. Fork the repository.
2. Clone your fork and create a branch.
3. Open `community/members.json`.
4. Add a new object to the list, using this format:

```json
{
  "name": "Your Name"
}
```

For example, if the file ends with:

```json
[
  {
    "name": "Systers Member"
  },
  {
    "name": "Add your name!"
  }
]
```

you can add a comma after the last object and then add your own:

```json
[
  {
    "name": "Systers Member"
  },
  {
    "name": "Add your name!"
  },
  {
    "name": "Your Name"
  }
]
```

Keep the square brackets, curly braces, quotation marks, and commas in the right places. JSON does not allow a comma after the final item.

5. Run `python main.py` from the repository root to check your change.
6. Commit, push, and open a pull request.

Use a first name or nickname—only share what you're comfortable making visible to the club.
