# Contributing to Systers Community

Thank you for contributing to Systers! This repository is a space to learn, share ideas, and collaborate. Contributions of all sizes are welcome.

## What can I contribute?

You can:

- Add a project idea to `community/PROJECT_IDEAS.md`.
- Share a learning resource or tutorial.
- Suggest an improvement to the repository.
- Fix a typo or improve documentation.
- Open an issue to ask a question or propose a project.
- Contribute code to a project as the repository grows.

You don't need prior GitHub experience to participate.

## How do I contribute?

For your first contribution, we recommend using the GitHub website.

1. Open the file you want to change.
2. Create a new branch.
3. Edit the file.
4. Commit your changes to your branch.
5. Open a pull request.
6. Ask for feedback and make any necessary changes.

See `WORKSHOP.md` for a detailed walkthrough.

## A few guidelines

- Be respectful and constructive.
- Keep contributions relevant to the community.
- Use clear headings and formatting.
- Don't share passwords, API keys, private contact information, or other sensitive information.
- Ask questions when you're unsure.
- Remember that this is a learning space; mistakes are part of the process.

## Reviewing contributions

Pull requests may be reviewed by club organizers or other contributors before they are merged. Feedback is an opportunity to learn, not a judgment of your abilities.

If you're new to GitHub, it's perfectly fine to ask someone to walk you through the process.

We're glad you're here!
